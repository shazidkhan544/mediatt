# Free Tuition Media — Starter Website

This is a responsive front-end MVP inspired by the functionality of tuition marketplace websites, but it does not copy their branding or source code.

## Run
1. Extract the ZIP.
2. Open `index.html` in a browser.
3. For best results use VS Code + Live Server.

## Included
- Homepage
- Tuition listing
- Search/filter
- Tuition details
- Tutor directory
- Tutor profile
- Post tuition form
- Registration/login demo forms
- About/contact/blog/legal pages
- Responsive CSS
- Sample tuition/tutor data

## Important
This is a front-end prototype. Forms do not persist data and login is not real authentication.

For production, connect it to WordPress/MySQL/API and add:
- real user authentication
- OTP verification
- admin approval
- database storage
- tutor verification
- application management
- email/SMS notifications
- abuse prevention/reCAPTCHA
- privacy/terms reviewed for Bangladesh
